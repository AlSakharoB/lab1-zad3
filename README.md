# Сложение и вычитание плотных матриц

Задача 3: сравнение времени сложения и вычитания матриц для трёх вариантов
программы. Тип элементов — `double`, вычисления выполняются в одном потоке.

| Программа | Вариант |
|---|---|
| `benchmark_baseline` | исходные циклы, `-O0`, автовекторизация отключена |
| `benchmark_compiler` | те же циклы, `-O3 -march=native` |
| `benchmark_simd` | SIMD-директива, выравнивание и `-fopenmp-simd` |

Нужны Linux x86-64, процессор с AVX2, GCC с поддержкой C++20, CMake 3.20+
и Bash. Генерация данных, выделение памяти и проверка результата выполняются
за пределами измеряемого интервала.

## Сборка и запуск трёх вариантов

```bash
bash run.sh --size 2048
```

Скрипт собирает три программы и запускает каждую с одинаковыми параметрами.
Для каждой выводятся время сложения и вычитания, минимум, медиана, максимум,
контрольная сумма и результат проверки корректности.

Можно задать прямоугольные размеры и выбрать одну операцию:

```bash
bash run.sh --rows 1000 --cols 1027 --operation add
bash run.sh --size 4096 --operation subtract --repeats 9
```

Для закрепления всех запусков за выбранным логическим процессором используется
переменная `BENCHMARK_CPU` (требуется `taskset`):

```bash
BENCHMARK_CPU=0 bash run.sh --size 2048
```

## Ручная сборка и отдельные запуски

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
./build/benchmark_baseline --size 2048
./build/benchmark_compiler --size 2048
./build/benchmark_simd --size 2048
```

По умолчанию выполняются обе операции для матриц 2048×2048. Используются два
прогревочных и семь измеряемых пакетов. Число вычислений в пакете калибруется
до достижения 100 мс; время делится на число вычислений. Матрицы создаются
с фиксированным seed, одинаковым для всех вариантов. Каждая строка выровнена
на 64 байта; размеры могут быть не кратны ширине SIMD.

Все параметры доступны через `--help`. Для вывода результата в CSV:

```bash
./build/benchmark_simd --size 2048 --csv-header
```

## Проверки корректности

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=ON
cmake --build build -j
ctest --test-dir build --output-on-failure
```

Проверяются известные суммы и разности, прямоугольные и пустые матрицы,
хвосты строк, сохранность входных данных и выравнивания, вычисления на месте,
некорректные параметры и переполнение размеров.

## Дополнительный вариант

Ручная AVX-версия с потоковой записью включается отдельно:

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DBUILD_STREAMING=ON
cmake --build build --target benchmark_streaming -j
./build/benchmark_streaming --size 4096
```

Она использует потоковую запись для больших матриц с отдельным выходным
буфером. Для маленьких матриц и вычислений на месте применяется обычный SIMD.
Время завершения потоковых записей входит в измерение.
